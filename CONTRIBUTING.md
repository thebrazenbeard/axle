# Contributing

AXLE is source-visible proprietary software.

Before submitting a pull request:

1. Read `LICENSE` and `CLA.md`.
2. State: **“I have read and agree to the repository CLA.”**
3. Identify third-party material and license/provenance.
4. Keep vehicle-bus effects read-only unless a separately approved scope says otherwise.
5. Run `make test`.

Do not include credentials, private vehicle identifiers, proprietary service data, or model files without redistribution rights.
