AXLE does not vendor the reference AI/audio projects in this bootstrap. They retain their own licenses.

Reference projects include ggml-org/llama.cpp, ggml-org/whisper.cpp, dscripka/openWakeWord, OHF-Voice/piper1-gpl, PipeWire/WirePlumber, NetworkManager, and Linux SocketCAN.

Model/data licenses can differ from code licenses. Review the exact deployed versions/assets before redistribution or commercial deployment.

No third-party source code is copied into the initial AXLE bootstrap.
